# PulseTrack Android

Portage natif (Kotlin + Jetpack Compose) de la PWA [PulseTrack](https://github.com/touilmohammed/pulsetrack), un journal sportif hors ligne. TP M2 Informatique, Università di Corsica.

## Lancer le projet

Ouvrir ce dossier dans Android Studio, puis Run sur un émulateur Google Play ou un téléphone (Android 8 ou plus).

En ligne de commande :

```bash
./gradlew assembleDebug
```
